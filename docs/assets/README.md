# Image provenance

No generative AI images are used in this repository.

- `orcaslicer-openanchor-tab.png`: unaltered screenshot from the actual isolated OpenAnchor-enabled OrcaSlicer 0.2 development build, captured during earlier native verification.
- `orcaslicer-preview.png`: unaltered actual two-material normal-anchor calibration Preview from the same native verification. It uses synthetic test presets and is not a physical printer result.
- `anchor-layout.svg`: generated from actual Beta 1 calibration specimen meshes using their bed-contact footprints. The top cap is intentionally omitted to expose beams and slots. Colors are explanatory.

The screenshots predate Beta 1 controls and do not establish live GUI verification for the advanced-beam release. No private models, third-party reference artwork or physical print photographs are included.
